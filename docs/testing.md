# 测试与验收

## 离线工程验证

```powershell
uv run --frozen python -m pytest -q -p no:cacheprovider
uv run --frozen ruff check --no-cache .
```

测试使用临时目录、模拟模型响应和 Qdrant 本地实现，验证格式解析、切块、混合排名、引用映射、重启恢复、导入重试、请求边界、上游向量响应类型、启动配置、目录迁移下载与源码打包排除规则。不会用测试预设答案替代正式业务模型。

离线测试检查代码行为与协议，不代表外部模型正确率，也不等同于 Docker 镜像构建成功。执行结果以当前环境实际输出为准。

## 真实服务验收

先生成虚构样例、配置服务并启动应用，保持 RERANKER_ENABLED=false：

```powershell
uv run --frozen python scripts/create_demo_data.py
docker compose up -d qdrant
uv run --frozen python main.py
# 在另一个终端执行
uv run --frozen python scripts/verify_live.py
```

脚本访问实际 HTTP 服务，上传三份样例，核对住宿标准600元、A100价格1299元及对应引用，检查去重和无依据问题。调用可能产生模型费用，报告保存在 data/live-verification.json，失败退出码为1。

该脚本为样例链路验收，不是通用准确率统计。改用业务文档后，需要重新制作人工预期答案与来源，不能沿用样例数字作为客户验收标准。

## 面向实际文档的问题集

至少覆盖直接查询、跨段落、表格数字、歧义、版本冲突及无答案问题。逐题分别判断：解析内容是否完整、检索是否命中、回答是否正确、引用是否支持结论。对延迟与调用成本单独记录实测值，不从离线测试耗时推断。

## 展示前检查

确认数据库与模型可调用、样例已完成索引、引用可以展开、原文可下载。使用当前版本录制实际操作；不要把旧环境截图、测试夹具返回或人工编写的示意回答当作实时运行证据。
