# 文档解析选型

## 当前使用

| 文件类型 | 依赖 | 用途 |
| --- | --- | --- |
| PDF | pdfminer.six | 提取文字、页码和文本框位置 |
| Word | python-docx | 读取段落和表格 |
| Excel | openpyxl | 读取工作表和单元格内容 |

PDF 解析结果通过 `PdfLoader` 转成统一的文本块，供后续切块、检索和引用使用。坐标统一为页面左上角原点，单位为点。

## 为什么选择 pdfminer.six

当前的 PDF 功能主要是文字提取和出处定位，pdfminer.six 能提供这两类信息，MIT 许可也便于后续部署和交付。页面渲染和 PDF 编辑不在当前功能范围内。

默认方案只读取文字层，不支持扫描件 OCR。多栏、竖排和特殊字体文件可能需要额外处理；裁剪页面的坐标以解析后的 MediaBox 为准，可能与阅读器中的裁剪视图不同。

## 何时考虑 PyMuPDF

如果后续需要页面渲染，或批量导入速度成为瓶颈，可以用实际文档评估 PyMuPDF。它提供更多 PDF 处理能力；本项目尚未进行两种解析器的性能对比。

未默认采用 PyMuPDF，主要是考虑后续交付的授权要求：它采用 AGPL / 商业双许可，接入时需要满足适用的 AGPL 条款，或取得相应商业授权。当前功能使用 pdfminer.six 即可实现，因此选择它作为默认依赖。授权条件见 [Artifex 官方说明](https://artifex.com/licensing)。

更换解析器需要修改 `traceable_rag/loaders.py` 中的 `PdfLoader`，保持文本块、页码和坐标输出一致，并验证引用位置。目前没有配置项可直接切换解析器。

## 已有索引

更换解析器不会自动重建已有索引，相同文件再次上传会被去重。需要重新解析时，可使用新的数据目录、上传目录和 Qdrant 集合重新导入，并保留原数据备份。
